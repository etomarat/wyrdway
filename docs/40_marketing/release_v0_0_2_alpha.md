# Wyrdway v0.0.2 alpha - release pack

Дата: 2026-03-15

## Positioning

Это не "большой gameplay update", а честный **controls/UI/feedback update**:

- играть стало удобнее
- меню и setup flow стали понятнее
- gamepad и rumble/haptics стали ближе к нормальному состоянию
- drive/readability стали лучше читаться на скорости

Не надо продавать релиз как "теперь новая игра". Лучше продавать его как:
"small but real player-facing update before the next bigger gameplay milestone".

Минимальный набор:

1. Короткий GIF `4-6` секунд:

   - затем finish gate / sparks / finish burst
2. Скрин setup / intro popup:
   - чтобы было видно, что билд поменялся не только "под капотом"
3. Скрин меню/опций:
   - prompts, difficulty, input/options persistence
