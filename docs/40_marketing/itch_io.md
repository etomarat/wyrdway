## Description (EN) — paste into itch.io

Wyrdway is a **retro road‑trip roguelite** you can play in the **browser** (and download for **Windows / macOS / Linux**).

You’re scavenging the backroads for scrap and fuel… and something is scavenging you.

#### Core loop
Drive → reach a POI → loot what you can → extract → **survive the return pressure** → get back to the garage → go again.

#### What’s in the build
- **Arcade top‑down driving** with drift/handbrake and strong feedback
- **Return chase**: a glitchy pursuer that bites your run loot and HP on the way home
- **POI raids (prototype)**: currently a simple timer + reward (full POI gameplay is planned)
- **Garage loop (prototype)**: repair and prep (upgrades are planned, not in yet)
- **Route/map (prototype)**: currently a simple selection screen (branching routes are planned)

#### Planned (subject to change)
- Garage upgrades and build customization
- Real POI gameplay layer (loot interactions, threats, decisions)
- Route map with branching choices and risk/reward
- Music + sound effects + stronger soundscape
- Visual polish + more content variety
- Story hooks and progression

#### Current state
This is a **work in progress / pre‑alpha** build. Expect frequent changes.

#### Controls
- **Keyboard**: Arrow keys + `X` (handbrake for drift)
- **Gamepad**: supported (not fully tested yet; keyboard recommended for now)
- **CRT filter**: toggle with `F6`

#### Platforms
- **Web (browser)**
- **Windows / macOS / Linux**

#### About TIC‑80
Wyrdway is built with **TIC‑80** (a tiny “fantasy console”) for a tight, bite‑sized retro feel — you don’t need to know anything about it to play.

#### Feedback
If you try the build, I’d love your feedback:
- What felt good?
- What was confusing?
- Did anything break?

## Media: скриншоты и GIF

### С чего начать (минимум, который уже хорошо работает)
- 1 **cover**: машина на дороге + читаемый намёк на аномалию/погоню (глич/молнии/стружка)
- 3–6 скриншотов: drive, POI, return chase, garage/result
- 1 короткий GIF (3–6 сек): момент дрифта или укус преследователя

### Небольшие тех‑советы по захвату (чтобы пиксель не “мылся”)
- Старайся захватывать кадры с **integer scaling** (кратно 240×136), чтобы не было блюра.
- Если будешь ресайзить картинки, используй **nearest neighbor** (без сглаживания).
- Лучше 1–2 «чистых» скрина без CRT, и отдельно 1–2 атмосферных с CRT (F6).

### Что показать в кадрах (чеклист)
- **Drive**: дрифт, дым/искры, скорость, читаемая дорога
- **POI**: таймер/давление, «быстро схватил и ушёл»
- **Return**: дистанция/наступление + FX (самая «уникальная» часть сейчас)
- **Garage/Result**: «привёз добычу → стал сильнее»

### Качество медиа (чтобы не терялось в ленте)
- Держи 1–2 «якоря» в каждом кадре: машина, дорога, UI‑элемент угрозы.
- Избегай кадра, где всё мелко и «шумно» без читаемой цели.
- Сделай 1–2 кадра с CRT (F6) и 1–2 без CRT, чтобы было из чего выбрать.

## Theme (цвета, шрифты, общий вид)

Баннер с Нивой подходит: читаемый силуэт, хороший контраст “тёплый мир” vs “холодная аномалия”, название заметно.

Сейчас тема выглядит немного “как консоль/терминал” из-за **Anonymous Pro** и того, что почти весь текст в моноширине. Это не “плохо”, но часто делает страницу менее дружелюбной для тех, кто просто листает.

### Вариант A (рекомендую): “Forest / Fog” — читаемо и по вайбу

В `Edit theme → Color`:
- `BG`: `#0f2c27` (тёмный лес)
- `BG 2`: `#d1c6ad` (тёплый туман/пыль, фон контента)
- `Text`: `#1b1b1b` (уголь)
- `Link`: `#1aa8b1` (аномальный cyan, как молнии на баннере)

В `Text` (быстрый вариант без экспериментов):
- `Font`: `Lato`
- `Header font`: `Lato` (или через `Select Google Font...`: `Rubik` / `Oswald`)

Правило: **пиксельный/моно‑шрифт только для акцентов**, а не для всего полотна.

### Вариант B: “Night Drive” — темнее и более “аномально”

Если хочется тёмную страницу (но следи за контрастом):
- `BG`: `#061816`
- `BG 2`: `#102f2a`
- `Text`: `#e9e4d7`
- `Link`: `#2ed0d8`

### Про TIC‑80 бейдж на баннере

Если цель — не отпугнуть “обычных” игроков, можно сделать второй вариант баннера **без TIC‑80 бейджа** и сравнить кликабельность/ощущение. Сам TIC‑80 у тебя уже вынесен вниз в тексте, так что баннер тоже может быть “просто про игру”.
