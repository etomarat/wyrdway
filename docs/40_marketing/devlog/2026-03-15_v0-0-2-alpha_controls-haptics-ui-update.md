# Wyrdway v0.0.2 alpha - controls, haptics, and UI update

Hey! Wyrdway **v0.0.2 alpha** is live.

This is a smaller player-facing update focused on **feel, readability, and controls** before the next bigger gameplay milestone.

## Highlights
- **New intro/setup flow** with a campaign seed editor and better save handling
- **Better controller support**: button prompts, rumble/haptics, saved input options, and vibration surviving reconnects
- **UI and menu pass** across the main menu, garage, region map, and result flow
- **Drive feedback pass**: finish burst, finish gate FX, sparks, fading road tails, and clearer shoulder line accents in turns

## What changed
- Added a new main menu scene with drive preview polish
- Added a new game intro popup sequence
- Added global options persistence and a difficulty setting
- Added mouse support in menus and setup flow
- Added a garage back action on the region map
- Improved HUD/control hints and overall overlay consistency

## Notes
- Current state: **pre-alpha**
- This update does **not** add the next major gameplay system yet
- The next bigger step is still a more meaningful gameplay update, not just more polish

## Feedback

- does **keyboard vs gamepad** feel better now?
- is the **rumble/haptics** too weak, too strong, or distracting?
