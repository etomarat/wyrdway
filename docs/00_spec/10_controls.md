# Управление (Controls)

Цель: сделать управление на геймпаде комфортным (не требовать постоянного удержания `UP`), при этом **не ломать клавиатуру**: `UP/DOWN/LEFT/RIGHT` должны работать как раньше.

Ограничение текущей сборки: TIC-80 по умолчанию даёт только цифровые кнопки геймпада `UP/DOWN/LEFT/RIGHT + A/B/X/Y`.

См. также: `80_misc/gamepad_face_button_mappings.md` (легенда по позициям South/West/East/North).

## Термины

- **D-pad**: `UP/DOWN/LEFT/RIGHT`.
- **Face buttons**: 4 кнопки `A/B/X/Y`.
- **Позиции face buttons** (для эргономики, независимо от надписей на пластике):
  - **South (нижняя)**: обычно "главная" кнопка (Xbox A / PS Cross / Nintendo B)
  - **West (левая)**
  - **East (правая)**
  - **North (верхняя)**

## Финальная раскладка (рекомендация)

### DRIVE: геймпад (TIC-80 default)

- Руль: `LEFT/RIGHT` (D-pad)
- Газ (ехать вперёд): **South** (держать)
- Ручник (часто): **West** (держать/тап)
- Тормоз/назад (редко): **East** (держать)
- Умение/рывок (skill/upgrade): **North** (тап)

Причины:
- большой палец убирается с `UP` и может комфортно рулить `LEFT/RIGHT`;
- ручник (частое действие) уходит на удобную "левую" фейс-кнопку;
- тормоз/назад остаётся отдельным действием, но не занимает самую удобную кнопку;
- умение выделено на отдельную кнопку без конфликтов с газом/ручником.

### DRIVE: клавиатура (как сейчас, не ломаем)

- Руль: `LEFT/RIGHT` (стрелки)
- Газ: `UP` (стрелка вверх)
- Тормоз/назад: `DOWN` (стрелка вниз)
- Ручник: `SPACE` (основной), `X` (альтернатива)
- Умение/рывок: `Z`

Примечание: даже если в будущем на геймпаде газ/тормоз переедут на триггеры, клавиатурная схема остаётся прежней.

## Дубли (чтобы ничего не “потрадало”)

Для совместимости и привычки:

- В DRIVE **всегда** принимаем `UP` как газ и `DOWN` как тормоз/назад (как минимум для клавиатуры).
- В DRIVE **добавляем** фейс-кнопки как альтернативный ввод для геймпада (South=газ, East=тормоз/назад, West=ручник, North=умение).

## План на будущее: триггеры (LT/RT) как дубликаты

Идея: триггеры не вводят новые действия, а **дублируют** существующие (чтобы не было конфликтов и “слоёв” логики).

Рекомендуемое дублирование:
- `RT` дублирует **газ** (South).
- `LT` дублирует **тормоз/назад** (East).
- `LB` дублирует **ручник** (West).
- `RB` дублирует **умение** (North).

Важно: если в кастомном билде TIC-80 триггеры/бамперы замаплены на те же
сигналы, что и face buttons (то есть отдельные id не добавляются), то игра
**не сможет отличить** нажатие `RT` от нажатия South. Это ок: конфликтов не
будет, но “какая именно физическая кнопка была нажата” определить нельзя.

Отсюда правило для UI: отображение подсказок (`RT` vs South) должно быть
**настройкой показа (prompt profile)**, а не попыткой “угадать” по вводу.

Если в кастомном билде появятся аналоговые оси:
- `RT`/`LT` могут стать аналоговыми (0..1), но логическая привязка остаётся той же: газ/тормоз.

## Подсказки в UI (prompt profiles)

Чтобы в UI можно было показывать альтернативные подсказки (например, “RT” рядом
с “South”), ввод (input) и отображение (prompts) надо разделить:

- **Input bindings**: какие сигналы реально принимаются для действия.
  Пример: `THROTTLE = [UP, South]`.
- **Prompt glyphs**: какие иконки/тексты показываем игроку для того же действия.
  Пример (варианты): `THROTTLE -> South` или `THROTTLE -> RT` (если включён
  профиль “triggers”).

Реализация: одно действие может возвращать **несколько глифов**, которые UI
форматирует как `(SOUTH)/(RT)` или `(SOUTH)/(RT)/[Z]`.

Настройки показа (черновик):
- Режим устройства: `gamepad`, `keyboard`, `both` (показывать только пад, только
  клавиатуру, или оба набора сразу).
- Детализация: показывать все глифы или только первый (primary only).

Правило для `both` (важно для читаемости UI):
- В режиме `both` показываем только **основные** подсказки для каждого варианта:
  - для геймпада: face buttons и D-pad (без шолдеров)
  - для клавиатуры: `[ENTER]`, `[SPACE]`, `[BACKSPACE]` и стрелки
- В режимах `gamepad` и `keyboard` можно показывать все варианты (альтернативы).

## UI/меню (для консистентности, черновик)

Это не жёсткая часть спеки, но хорошее правило:
- `A`/South: подтвердить/выбрать
- `B`/East: назад/отмена
- `X`/West: вторичное действие
- `Y`/North: подсказка/инфо/третье действие

Клавиатура (органичный дефолт без Esc):
- Confirm: `[ENTER]` (основной), `[Z]` (альтернатива)
- Cancel: `[BACKSPACE]` (основной), `[X]` (альтернатива)
