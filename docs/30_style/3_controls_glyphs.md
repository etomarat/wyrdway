# Wyrdway — UI глифы кнопок (controls glyphs)

Цель: зафиксировать контракт для UI-подсказок (какие глифы существуют) и
подготовить место под будущие спрайты.

Пока спрайтов нет, UI может отображать текстовые фоллбеки вида `[SOUTH]/[RT]`.

## Набор глифов (канон)

### Gamepad (позиции фейс-кнопок)

- `SOUTH`
- `WEST`
- `EAST`
- `NORTH`

Почему позиции, а не буквы: буквы `A/B/X/Y` отличаются на Xbox/PS/Nintendo, а
позиции стабильны.

### Gamepad (шолдеры/триггеры)

- `LT`
- `RT`
- `LB`
- `RB`

Примечание: в кастомном билде TIC-80 эти кнопки могут быть замаплены на те же
сигналы, что и фейс-кнопки. В UI мы всё равно можем показывать оба обозначения
как “синонимы”.

### Keyboard (текстовые ярлыки)

Формат: всегда в квадратных скобках.

- `[UP]`, `[DOWN]`, `[LEFT]`, `[RIGHT]`
- `[Z]`, `[X]`, `[A]`, `[S]`
- `[ENTER]`, `[SPACE]` (на будущее для системных/менюшных подсказок)
