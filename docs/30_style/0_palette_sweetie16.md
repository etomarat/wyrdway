# TIC-80 — дефолтная палитра (SWEETIE-16)

Источник правды: `docs/20_tech/TIC-80.wiki/Palette.md`.

TIC-80 по умолчанию использует палитру **SWEETIE-16** (16 цветов, индексы 0..15).

| 1     | Purple      | 5D275D  |

| 15    | Dark Grey   | 333C57  |

## Полезные подсказки для кода

- “Безопасные” нейтральные цвета для UI/FX, чтобы не путать с дорогой:
  - белый `12`, серые `13/14/15`
- Дорога сейчас использует зелёные оттенки (`5/6/7`), поэтому для следов/дыма лучше
  не брать зелёный (иначе “сливается”).
