# UI Style Guide (v0)

Этот документ фиксирует базовые правила интерфейсов в текущем стиле `Wyrdway`.

## 1. Общие принципы

- Читаемость важнее декоративности.
- Любой экран строится из панелей с четкой рамкой и понятной иерархией.
- Основной контент держим в безопасной зоне, без прилипаний к краям `240x136`.
- Управление всегда видно через prompt-глифы (не текстом вроде `PRESS Z`).

## 2. Визуальные правила

- База: `BLACK` фон + рамки `GREY`/`DARK_GREY`.
- Заголовки секций: `LIGHT_GREY` или `WHITE`.
- Активный пункт меню: `YELLOW`.
- Вторичный текст/описания: `LIGHT_GREY`.
- Опасные действия и системные ошибки: `RED`.

## 3. Лейаут главного меню

- Верхняя полоса: логотип + версия.
- Ниже две колонки:
- Левая: `MAIN MENU` + список действий + контекстный блок сейва.
- Правая: геймплейный превью-виджет (`ENTITY WATCH`).
- Колонки визуально равноправные, с единой толщиной рамок и отступами.

## 4. Правила модалок

- Модалка центрируется на экране, с отдельной шапкой, телом и футером.
- В футере всегда показываются кнопки действий (confirm/cancel/close) через prompt-глифы.
- Если текста больше, чем вмещает тело модалки, включается вертикальный скролл:
- `NAV_UP / NAV_DOWN` двигают текст.
- Визуально показываем, что есть скролл (индикаторы вверх/вниз).
- Для destructive-подтверждений используем явный `CONFIRM` + `CANCEL`.

## 5. Контент и копирайтинг

- Тексты короткие, в верхнем регистре, без длинных абзацев.
- Заголовок модалки должен отвечать на вопрос: "что сейчас решает игрок?"
- Подсказки кнопок формулируются как действие: `CLOSE`, `CONFIRM`, `CANCEL`, `SCROLL`.

## 6. Техническая реализация

- Переиспользуем общие UI-хелперы из `core/ui/*` (`rich_text`, `prompts`, `panel`, `modal`).
- Новые сцены не копируют стили вручную, а следуют этим правилам.
- Любое отклонение (новая визуальная тема) должно быть осознанно описано в `docs/30_style`.
