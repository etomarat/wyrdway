# Wyrdway — раскладка спрайтов (TIC-80)

Цель: зафиксировать, **какие спрайты где лежат**, какого они размера и как их правильно рисовать.
Это снижает шанс “сдвига атласа” и поломки рендера при добавлении новых ассетов.

## База TIC-80

- Базовый спрайт в TIC-80 — **8×8 пикселей** (1 “тайл” на спрайт‑листе).
- Вызов `spr(id, x, y, ..., w, h)` умеет рисовать **составной** спрайт из `w×h` тайлов.
- Индекс `id` у `spr()` — **0..511** (две “страницы” по 256 спрайтов).

Полезная математика (для ориентира):
- `page = id // 256` (0 или 1)
- `local_id = id % 256`
- `tile_x = local_id % 16`
- `tile_y = local_id // 16`

## Принцип раскладки больших спрайтов

Если ассет 32×32, то он занимает **4×4 тайла** 8×8.

Правило: базовый `id` должен указывать на **левый верхний** тайл блока 4×4 и быть выровнен по сетке.

Рисование 32×32:
```python
spr(BASE_ID, x, y, colorkey, scale, flip, rotate, 4, 4)
```

Примечание: в TIC-80 нет альфа‑канала, прозрачность задаётся `colorkey`. Пока
используем `colorkey = 0` (если окажется, что фон не 0 — уточним и обновим этот документ).

## Машина “Нива” (top-down, 32×32)

Расположение: **с самого начала второй страницы спрайтов**, начиная с `id = 256` (это `page=1`, `tile_x=0`, `tile_y=0`).

Порядок кадров (как загружено в картридж):
1) вперёд
2) поворот влево
3) поворот вправо

### Таблица кадров

| Кадр | Назначение | Размер | BASE_ID | Тайл-коорд (page, x, y) |
|---|---|---:|---:|---|
| 0 | Niva forward | 32×32 (4×4) | 256 | (1, 0, 0) |
| 1 | Niva left | 32×32 (4×4) | 260 | (1, 4, 0) |
| 2 | Niva right | 32×32 (4×4) | 264 | (1, 8, 0) |

Примечание: шаг `+4` по `BASE_ID` потому что каждый кадр занимает 4 тайла по ширине.

### Рекомендованные имена констант (для будущего кода)

- `SPR_NIVA_TOPDOWN_FWD_BASE = 256`
- `SPR_NIVA_TOPDOWN_LEFT_BASE = 260`
- `SPR_NIVA_TOPDOWN_RIGHT_BASE = 264`
- `SPR_NIVA_TILE_W = 4`
- `SPR_NIVA_TILE_H = 4`

## Резервы на будущее (предложение)

Чтобы не плодить легаси, лучше заранее договориться о диапазонах:
- `256..` — транспорт/игрок (крупные 32×32 и UI‑варианты)
- дальше — препятствия/зоны/FX

Когда добавляем новый крупный ассет:
1) выбираем диапазон в этой таблице,
2) фиксируем `BASE_ID` и размер,
3) обновляем документ.
