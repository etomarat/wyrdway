# Contributing

Thanks for your interest in contributing to Wyrdway.

## License note (important)

This repository uses a **source-available** license with **no redistribution**.
Please read `LICENSE` before contributing.

By submitting a pull request (or any contribution), you agree that:
- your contribution is your original work (or you have the right to submit it)
- your contribution is licensed under `LICENSE`
- the project owner may use, modify, relicense, and distribute your contribution

## How to contribute

1) Create a fork (public forks are allowed only for PR workflow).
2) Make a focused change with a clear description.
3) Open a pull request.

## What not to do

- Do not upload builds/exports/releases from this repo.
- Do not mirror/re-publish the repo as a separate project release.
